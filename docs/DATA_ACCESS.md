# Data availability

The project uses synthetic data created for academic purposes. The public portfolio contains methodological documentation, analytical code, aggregate outputs and static report views.

The prepared record-level tables and editable Power BI file are not publicly distributed in this repository. Access may be considered upon reasonable request, subject to prior agreement from the project participants and any applicable conditions on collaborative materials. This statement is not a promise of unrestricted access.

The notebook reads five approved CSV inputs; it does not generate a substitute dataset or silently change missing values. The separate input archive supplied to the portfolio owner is for controlled execution and is not part of the public repository.

No data folder, CSV inputs, SQLite database or PBIX file is required to view the published report and executed notebook. Those inputs are required to rerun the analysis.
