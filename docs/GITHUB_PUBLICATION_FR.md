# Mise en ligne sur GitHub

Le dossier `Parts_and_Suppliers_Portfolio` constitue le contenu du dépôt public. Son fichier `README.md` est la page de présentation, en anglais. Les crédits des trois participants figurent dans le README, dans la documentation et dans le notebook.

Le ZIP `Parts_and_Suppliers_Private_Inputs.zip` est fourni séparément pour exécuter le notebook avec les données corrigées. Il doit rester hors du dépôt public. Il ne contient pas le PBIX. La publication des données reste soumise à l'accord de l'équipe.

Le dépôt public contient le notebook professionnel exécuté, les requêtes SQL, les principales mesures DAX, les captures des quatre pages, le rapport PDF et la couverture originale. Aucun tutoriel, script de présentation ou checklist pédagogique de l'ancien notebook n'est conservé.

Le rapport PDF et les captures présentent le travail sans proposer le fichier PBIX au téléchargement. Comme tout fichier rendu public sur GitHub, ces documents et le notebook peuvent être téléchargés.

Le fichier `.gitignore` exclut les extensions de données et les fichiers PBIX. Il ne supprime pas des fichiers déjà suivis dans un dépôt existant. Ce dossier est prévu pour un nouveau dépôt contenant uniquement les éléments de l'archive publique.
